Core2 user interface mockups, firmware 1.2 (round 3)

Each screen is the Core2's real 320×240 pixels in Montserrat, LVGL's built-in font, with the touch strip and its three circles underneath. The sample data is the TUI mockups' TH-D75 bridge.

Scale

Decided so far

  • Tabs along the top move between pages: Bridge, TNC, System. A fourth tab fits later.
  • The circles are soft keys, labelled on the screen's bottom edge when a screen has something for them. Left: back, cancel, no. Middle: the screen's main action. Right: yes, OK, confirm. Long presses on them are kept free for later.
  • Flows lock the tabs (scanning, pairing, settings, power off), and the left key gets you out.
  • The TNC page's action is the middle key.
  • The Bridge page always shows the device's name, in the Apps heading ("Apps on KTB-EF26"), apps or not. It's how you tell bridges apart, in place of the ATOM's identify. System keeps it too.
  • App addresses are shown, though phones change them; the docs explain why.
  • RX and TX count since that link connected, for the radio and for each app. Times are durations ("2h 14m"), since the device has no clock set in 1.2. The same counts for the TUI: kotfu/kiss-tnc-bridge#18.
  • No authorization mode in 1.2.
  • Errors show as a banner where they happen; tapping it opens System with the whole message.
  • Screen modes: screen_normal is bright, dim or dark, as the LED's are. Dim: the backlight drops after the timeout, and a touch brightens it and acts. Dark: the screen goes off, and the first touch only wakes it. To refine on the device.
  • The timeout is screen_timeout_seconds, 30 by default, the same on battery and on USB, since USB power may be another battery.
  • The battery indicator is option D: the number and the battery, the level grey on battery, striped green and moving while it charges, solid green when full on external power, red at 20% and under.
  • The power button toggles the screen with a short press.
  • The screen wakes for an error, and when the radio or an app connects or disconnects. Not for frames.
  • Brightness is fixed in 1.2.
  • Power off is the middle key on System, with a confirmation.

Questions to settle

  • The default mode: dim, since the default is "30 s before dimming"? Drawn that way here.
  • Power off on USB: whether the AXP192 stays off with USB plugged in, or starts again at once, needs checking on the Core2. If it starts again, the confirmation should say so.
